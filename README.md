# Startup Lab KZ

Самостоятельные продукты на основе изученных задач и публичных продуктовых референсов. В каталоге **100 референсов**. Реализован **один продукт: SabaqLoop 0.1**. Два референса учебной категории относятся к этому одному продукту; остальные 98 пока остаются исследованием.

## SabaqLoop

[Открыть приложение](https://wpalish.github.io/startup-lab-kz/sabaqloop/) · [Как устроено](https://wpalish.github.io/startup-lab-kz/sabaqloop/about.html)

Практика из материала преподавателя: наборы, вопросы с источниками, проверка перед практикой, ответы и объяснения, повторение ошибок, история версий и JSON-копии.

```sh
npm test
npm run build
npm run preview
```

Открыть `http://127.0.0.1:8781/sabaqloop/`. Нужны Node.js 22+ и Python 3. Зависимостей из npm нет. Для отдельного приложения: `npm start --prefix apps/sabaqloop` и порт 8780.

## Что действительно работает

- Создание наборов и ручных заданий с обязательным исходным фрагментом.
- Черновики с пропуском слова из собственного текста. Генерация по правилам, без AI API.
- Явное одобрение преподавателем. Редактирование создаёт новую версию и снимает одобрение.
- Короткий ответ и выбор одного варианта, объяснение и источник после ответа.
- Ошибки и очередь повторений; интервалы 1/3/7/14/30 дней после правильных ответов.
- История сохраняет снимок исходного вопроса и оценки.
- Валидация резервных копий, предварительный просмотр перед импортом и сохранение предыдущей копии.
- Защита от перезаписи устаревшей вкладкой при обнаружении другой ревизии, отказ вместо сброса повреждённых данных.

## Границы

Это локальный браузерный прототип, **не облачная LMS**. Один браузер — одна рабочая область. Ученик и преподаватель не имеют отдельных защищённых аккаунтов. Нет backend, платежей, AI-оценивания, контроля экзамена, облачной синхронизации или проверенного учебного результата. Не хранить персональные данные учеников. Экспортировать копии: браузер может очистить localStorage.

RU-интерфейс, материалы RU/KK/EN/mixed. Три оригинальных английских примера — не официальный IELTS. Короткие ответы проверяются по явно заданным вариантам, а не по смыслу.

Публичные описания Knowt и Quizgecko были референсами категории. Их код, дизайн и учебный контент не копировались. Их внутренние дефекты не исследованы. Источники, версии и проверка в этом приложении — наши реализованные решения, а не доказанные преимущества над конкурентами.

## Репозиторий

`apps/sabaqloop/dist` — все исполняемые файлы приложения; `apps/sabaqloop/tests` — доменные тесты; `scripts/build.mjs` — сборка статических файлов; `.github/workflows/pages.yml` — тестирование и GitHub Pages. Сборка переносит только явный список пользовательских файлов: рабочие заметки и данные браузера не публикуются.
