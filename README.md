# Startup Lab KZ — индекс программы

Каталог 100 продуктовых референсов для Казахстана и СНГ и ссылки на отдельные реализации. **Каждый продукт разрабатывается в собственном репозитории.** Здесь находятся исследование и индекс, а не общая кодовая база приложений.

| Продукт | Референс | Фактический статус | Репозиторий | Демо |
|---|---|---|---|---|
| SabaqLoop | #43 Knowt | Локальный браузерный прототип; 14 тестов и публичный сценарий проверены. 10 потенциальных компаний исследованы, спрос не подтверждён. | [wpalish/sabaqloop](https://github.com/wpalish/sabaqloop) | [Открыть](https://wpalish.github.io/sabaqloop/) |

Один продукт не засчитывается за два референса. #45 Quizgecko остаётся отдельной задачей. Полная функциональность всех 100 продуктов пока не реализована.

Проверяются конкретные сценарии, источники, сохранение данных и ошибки. Недостатки референсов считаются подтверждёнными только по проверке или официальному источнику; прочие предложения остаются гипотезами.

Подписка, неэксклюзивная лицензия на код, внедрение и продажа бизнеса — разные сделки. Репозиторий и демо не доказывают спрос, выручку или пригодность к продаже целого бизнеса.

## Локальный просмотр индекса

```sh
npm run build
npm run preview
```

Открыть http://127.0.0.1:8781/. Код и тесты каждого продукта находятся в его собственном репозитории. Старый адрес SabaqLoop переводит на новое самостоятельное демо.

История первоначальной реализации сохранена в Git; действующий код SabaqLoop перенесён. Коммерческие права автоматически не выдаются: см. LICENSE в продукте.
